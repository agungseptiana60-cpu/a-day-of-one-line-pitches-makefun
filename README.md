One sentence, written for a friend who has never coded: that app idea you keep talking about could exist tonight — just describe it in your own words on make.fun, and an AI agent builds your first version, no code to learn and no experience needed. The program in `main.ts` writes that single sentence (205 characters) to `entry.txt` in the output directory, after checking it fits the 1–240 character gate.

## Run it

```sh
node main.ts
```

This writes `/output/entry.txt`. Outside the grader, set `MAKEFUN_OUTPUT_DIR` to choose the output directory.
